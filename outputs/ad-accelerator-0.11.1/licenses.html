Filter data

HaGeZi’s DNS blocklists provide Multi Light, Threat Intelligence Mini and Popup Ads domain data, distributed under GPL-3.0. Original source snapshots, attribution, hashes and license text are included in the extension package.

EasyList, by the EasyList authors, supplies bundled cosmetic filter data. We use the GPL-3.0-or-later licensing option. The transformed subset, complete source snapshot and transformation script are included in the package. It includes generic simple CSS rules, not the full EasyList feature set.

See filters/NOTICE.md, filters/LICENSE-HaGeZi.txt, filters/provenance.json, and scripts/build-filters.cjs in the extension download for the corresponding notices, source and transformation details.
